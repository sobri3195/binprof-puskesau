# Analisis referensi

Lampiran pengguna mendeskripsikan pengamatan publik pada halaman login beserta nama rute yang terlihat pada bundle. Implementasi menggunakan spesifikasi tersebut dan rancangan antarmuka orisinal. Peninjauan ini menggunakan aplikasi lokal dengan data sintetis. Halaman internal dan integrasi pada situs referensi belum diverifikasi.

Halaman utama menyajikan autentikasi email dan kata sandi, serta navigasi terpisah untuk ikhtisar, personel, pendidikan dan pelatihan, peta, notifikasi, audit, dan akun. Server menyimpan sesi, membatasi cakupan, dan mengautentikasi seluruh operasi. Aset geografis, grafik, 2D, dan 3D dikemas lokal. Hak administratif mengikuti peran dan cakupan. Paket source tidak mengimpor akun, koordinat, catatan, atau data pengguna dari situs referensi.
